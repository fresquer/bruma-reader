# Bruma landing screenshots

These PNGs are genuine, unretouched captures from the X4 desktop simulator
(`.pio/build/simulator/program`), captured on 2026-10-19 at 960 × 1600 pixels
(2× the 480 × 800 logical screen).

The simulator used an isolated SD directory, English (`language: EN`), and the
optional Bruma theme (`uiTheme: 6`, `uiThemeSchemaVersion: 3`). The sample library
and reading text are demonstration data, not a reproduction of the named books.

- `home.png`: current book, recent reads and inherited reading statistics.
- `library.png`: actual catalog generated by scanning the sample SD directory.
- `reading.png`: English demonstration text, after five manual page advances,
  with a chapter time estimate in the reading status bar.

These captures show software behavior, not physical panel refresh or tones.
No reader was flashed or connected for their production.
